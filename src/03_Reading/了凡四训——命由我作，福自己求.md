# 《了凡四训》—— 命由我作，福自己求

:::info
立命之学：荣辱生死，皆有定数。命由我做，福自己求。一切福田，不离方寸；从心而觅，感无不通

:::



孔先生算定“荣辱生死，皆有定数”，

诗书中提出“命由我做，福自己求”；

孟子：“一切福田，不离方寸；从心而觅，感无不通”；

《诗经》：“永言配命，自求多福”。——要恒常配合天命行事，自己谋求更多的福分



箴言：“即命当容显，常作落寞想；即时当顺利，当作拂逆想。即眼前足食，常作贫窭想。即人相爱敬，常作恐惧想。即家世望重，常作卑下想。既学问颇优，常作浅陋想。”

务要日日知非，日日改；，一日不知非，即一日安于自是；一日无过可改，即一日无步可进。



:::info
改过之法：要含有对坏习性的羞耻心、对事物的敬畏心、果断执行改正的勇敢心；改过之法事、理、心由浅到深，最好的改过之法就是修心

:::
