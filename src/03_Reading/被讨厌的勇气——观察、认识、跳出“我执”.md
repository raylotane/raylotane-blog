# 《被讨厌的勇气》——观察、认识、跳出“我执”


补充的新颖观点：

1. 目的论。因果关系衍生出原因论，其实质是借原因为理由去达到想要的目的（结果），这种行为应该被认识为目的论。并不是因为某个原因造成的结果，而是恐惧结果，为其找的理由。
2. 一切烦恼都来自人际关系。交友课题、工作课题以及爱的课题为人生三大课题，认识到课题分离，在人际交往中辨认出自己与他人的课题，把自己和别人的“人生课题”分开来。



## 课题分离
一切烦恼都来自人际关系，一切人际关系矛盾都起因于对别人的课题妄加干涉或者自己的课题被别人妄加干涉，只要把自己和别人的课题分开来，人际关系就会发生巨大改变。



通过“某种选择所带来的结果最终由谁来承担？”思想来辨认是谁的课题。



援助，不是干涉他人课题，就像谚语：“可以把马代到水边，但不能强迫其喝水”。



不去干涉别人的课题也不让别人干涉自己的课题。



## 金句
+ 无论之前的人生发生过什么，都对今后的人生如何度过没有影响
+ 决定我们自身的不是过去的经历，而是我们自己赋予经历的意义
+ 困恼我们的自卑感不是“客观性的事实”而是“主观性的解释”
+ 重要的不是被给予了什么，而是如何去利用被给予的东西
+ 健全的自卑感不是来自与被人的比较，而是来自与“理想的自己”的比较
+ 要分清“能够改变的”和“不能改变的”。
+ 我们无法改变“被给予了什么”，但是，关于“如何去利用被给予的东西”，我们却可以用自己的力量去改变。这就是不去关注“无法改变的”，而是去关注“可以改变的”，这就是我所说的自我接纳。
+ 请赐予我平静，去接受我无法改变的；给予我勇气，去改变我能改变的；赐我智慧，分辨这两者的区别。
